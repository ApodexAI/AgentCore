`OpenAIResponsesClient.stream` now streams function-call arguments and returns the completed response's verbatim block list (`encrypted_content` reasoning + function calls in provider order), so a streamed Responses turn replays exactly like the non-streaming one; previously streaming dropped every tool call and reasoning item. `responses` is removed from `UNVERIFIED_STREAM_PROTOCOLS`, so it now streams automatically when an observer or the reasoning-only watchdog asks for deltas.
